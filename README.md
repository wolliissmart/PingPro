PingPro is a simple, but lightweight Minecraft-Plugin to ping you and other players. 

To ping yourself, use the command: "/ping". 
To ping other players, use the command: "/ping [Player]"

There are two permissions:
"pingpro.ping" is the permission to ping yourself. Every player gets it by default. 
"pingpro.ping.get" is to ping other players. By default, only OPs have this permission.
